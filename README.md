# 🌌 HopeOS

**HopeOS** — это моя первая авторская операционная система, разрабатываемая полностью с нуля, включая собственный загрузчик (bootloader), ядро (kernel) и уникальные низкоуровневые методы управления системой.

Цель проекта — изучить архитектуру ЭВМ на самом глубоком уровне и создать независимую, надежную программную среду.

## 🔑 Защита проекта и Авторские права
Исходный код HopeOS защищен лицензией **GNU GPL v3.0**. 
* Вы можете изучать код и запускать систему.
* **Запрещено** присваивать код, закрывать его или использовать уникальные методы ядра в проприетарных (закрытых) коммерческих проектах без открытия их исходного кода. Любое производное ядро должно оставаться открытым и ссылаться на HopeOS.

## 🚀 Архитектурные особенности
*   **Собственный загрузчик (Bootloader):** Написан вручную, отвечает за первичную настройку процессора, переход в защищенный режим и передачу управления ядру.
*   **Собственное ядро (Kernel):** Реализует авторские методы управления процессами, памятью и прерываниями.
*   **Полная независимость:** Проект не использует готовые решения вроде GRUB или готовые шаблоны ядер.

## 🛠 Инструменты для сборки и запуска
*(Раздел будет дополняться по мере разработки)*
Для компиляции и тестирования HopeOS вам понадобятся:
*   Ассемблер (например, `nasm`)
*   Компилятор C/C++ (например, `gcc`)
*   Эмулятор `QEMU` или `VirtualBox` для запуска готового образа системы.

## 📂 Структура репозитория
*   `/boot` — исходный код кастомного загрузчика.
*   `/kernel` — код ядра операционной системы и уникальные методы.
*   `/docs` — документация и описание логики работы моих методов.
